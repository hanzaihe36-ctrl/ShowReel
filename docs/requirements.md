# 需求规格说明

## 项目概述
游戏特效师个人作品集展示网站，用于应届生求职展示。

## 用户画像
- 求职意向为游戏特效师的大学在校生
- 不懂代码
- 需要向面试官展示作品和能力

## 页面列表（5个独立页面）

### 1. 首页（index.html）
- **定位**：网站入口，个人品牌第一印象
- **内容**：姓名、头衔（游戏特效师）、简短Slogan、引导按钮（跳转作品集）
- **风格**：居中布局，简洁有力，一屏展示

### 2. 作品集（portfolio.html）
- **定位**：核心页面，展示主打作品
- **内容**：
  - 页面标题区（如"作品展示"）
  - 单个主打视频播放器（大尺寸居中）
  - 作品信息区：作品名称 + 技术说明 + 创作思路
  - 视频使用 HTML5 `<video>` 标签，支持播放控制
- **素材**：用户提供一个 MP4 长视频文件

### 3. 技能展示（skills.html）
- **定位**：展示专业技能和软件熟练度
- **内容**：
  - 技能分类（如：游戏引擎 / 3D软件 / 2D设计 / 其他）
  - 每项技能配进度条或星级
  - 视觉化呈现
- **素材**：用户提供技能清单和熟练度

### 4. 关于我（about.html）
- **定位**：个人背景 + 简历
- **内容**：
  - 个人介绍文字（教育背景、经历、创作理念）
  - 简历 PDF 内嵌预览
  - 简历下载按钮
- **素材**：用户提供个人介绍文字 + 简历 PDF

### 5. 联系我（contact.html）
- **定位**：联系方式展示
- **内容**：
  - 邮箱（考虑防爬虫处理）
  - 微信二维码（可选）
  - 社交账号链接（B站/ArtStation/等）
- **素材**：用户提供联系方式

## 全局功能
- 顶部固定导航栏（5项 + 当前页高亮）
- 页脚（版权信息）
- 响应式设计（桌面端 + 手机端）
- 统一淡蓝色主题

## 非功能需求
- 纯静态，无后端
- 加载速度快
- 手机可正常浏览
- 视频支持 HTML5 原生播放
