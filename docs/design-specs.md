# 设计规范

## 色彩系统

| 令牌 | 色值 | 用途 |
|------|------|------|
| `--primary` | `#5B9BD5` | 主色：导航栏、按钮、链接、进度条 |
| `--primary-dark` | `#3A7BC8` | 主色深：按钮 hover、导航当前项 |
| `--primary-light` | `#D6E8F7` | 主色浅：卡片背景、区块底色 |
| `--bg` | `#FFFFFF` | 页面背景 |
| `--bg-light` | `#F5F8FC` | 浅灰蓝背景：交替区块 |
| `--text` | `#2C3E50` | 主文字色 |
| `--text-light` | `#7F8C8D` | 辅助文字色 |
| `--text-white` | `#FFFFFF` | 深色背景上的文字 |
| `--border` | `#E1E8ED` | 边框线 |
| `--shadow` | `rgba(0,0,0,0.08)` | 卡片阴影 |

## 字体层级

| 层级 | 字号（桌面/移动） | 字重 | 用途 |
|------|-------------------|------|------|
| H1 | 48px / 32px | 700 | 页面主标题 |
| H2 | 32px / 24px | 600 | 区块标题 |
| H3 | 24px / 20px | 600 | 卡片标题 |
| Body | 16px / 15px | 400 | 正文 |
| Small | 14px / 13px | 400 | 辅助文字、标签 |
| Caption | 12px / 11px | 400 | 脚注 |

**字体栈**：`"PingFang SC", "Microsoft YaHei", "Helvetica Neue", Arial, sans-serif`

## 间距系统（8px 基准）
- `--space-xs`: 4px
- `--space-sm`: 8px
- `--space-md`: 16px
- `--space-lg`: 24px
- `--space-xl`: 32px
- `--space-2xl`: 48px
- `--space-3xl`: 64px

## 响应式断点
- **移动端**：< 768px（默认样式，移动优先）
- **平板**：768px ~ 1024px
- **桌面端**：> 1024px

## 通用组件样式

### 导航栏
- 固定顶部，高度 64px
- 背景白色 + 底部细边框
- 导航项横向排列，当前页高亮（主色文字 + 底部色条）
- 移动端：汉堡菜单折叠

### 按钮
- 主按钮：主色背景 + 白色文字 + 圆角 8px
- 次按钮：主色边框 + 主色文字 + 透明背景
- hover 态：颜色加深、轻微上浮阴影

### 卡片
- 白色背景 + 圆角 12px + 轻微阴影
- hover 态：阴影加深 + 轻微上浮

### 页脚
- 浅灰蓝背景
- 版权文字居中
- 高度约 80px

### 容器
- 最大宽度 1200px
- 居中，左右 padding 24px（移动端 16px）

## 图标方案
- 使用简单的 CSS 绘制或 Unicode 符号
- 不引入图标字体库（保持零依赖）
- 技能图标使用 SVG 内联或 emoji 占位
